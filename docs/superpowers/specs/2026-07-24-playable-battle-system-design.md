# 可玩闭环战斗系统设计

## 目标

在现有基础战斗内核上，完成一个可测试、可扩展、可游玩的服务端战斗系统闭环。所有已有英雄、战法、武器/装备都必须能接入战斗流程；核心数值、常见伤害、状态、装备效果必须生效；暂时无法精确还原的复杂效果必须生成可观测 fallback 事件，不能静默失效或阻塞战斗。

## 非目标

- 不承诺一次性 100% 精确还原商业服全部战法文本分支。
- 不承诺本轮完成客户端动画 DSL 的完整兼容格式。
- 不包含行军、地块耐久、经验奖励、资源结算、PVP 排行等战斗外围系统。

## 架构

采用统一效果管线。英雄、战法、武器/装备都先转换成统一的战斗修饰器或战斗效果，战斗引擎只消费统一接口，避免英雄逻辑、装备逻辑、战法逻辑在回合循环里互相穿插。

核心模块：

- `BattleContext`：承载当前回合、双方运行时单位、随机源、事件流。
- `BattleUnit`：由英雄配置、等级成长、兵力、战法、装备合成出的运行时武将。
- `BattleModifierPipeline`：统一应用英雄成长、组合加成、装备属性、被动战法、增伤减伤。
- `BattleSkillRuntime`：处理战法释放条件、准备回合、冷却、发动率、目标选择和效果执行。
- `BattleEquipmentRepository` / `BattleEquipmentApplier`：加载 `gear_id.json`、`gear_feature_extra.json`，输出属性和战斗效果。
- `BattleReportCodec`：继续输出稳定 JSON 和 `zzz` 压缩报告。

## 数据流

1. `BattleTeamBuilder` 接收英雄规格：英雄 ID、等级、兵力、站位、额外战法、装备 ID。
2. 配置仓库加载英雄、战法、战法详情、战法效果、组合、装备和装备特性。
3. Builder 生成 `BattleUnit` 或兼容的 `BattleHero`，附带技能、装备、成长后属性和静态修饰器。
4. 战斗初始化阶段应用：
   - 英雄等级成长。
   - 队伍组合加成。
   - 装备基础属性。
   - 被动/指挥类战法。
   - 装备常驻特性。
5. 每回合每个单位行动时：
   - 先检查控制状态。
   - 更新准备/冷却。
   - 判定可释放战法。
   - 选择目标。
   - 执行效果。
   - 如无可释放战法，执行普通攻击。
6. 伤害、恢复、状态变更、fallback 都写入事件流。
7. 战斗结束后输出 `BattleResult` 和战报。

## 支持效果范围

本轮必须支持：

- 属性提高/降低：攻击、防御、谋略、速度、攻城、攻击距离。
- 伤害：普通攻击、攻击伤害 `301`、策略攻击伤害 `302`。
- 恢复：急救/休整类基础兵力恢复。
- 状态：混乱、犹豫、暴走、怯战、洞察、规避。
- 修饰：造成伤害提高/降低、受到伤害提高/降低、主动战法伤害提高/降低、普通攻击伤害提高/降低、无视部分防御。
- 战法运行时：发动率、准备回合、冷却回合、目标数量、敌我目标选择、可用回合。
- 装备：`gear_id.json` 中 `skillDesc` 的直接属性和常见伤害修饰；`gear_feature_extra.json` 中常见特性。

不支持或无法可靠解释的 effect 必须产出 `UnsupportedSkillEffect` 或 `UnsupportedEquipmentEffect` 事件，包含来源 ID、效果 ID、原始描述和回合信息。

## 错误处理

- 缺失英雄配置：构建队伍时报错。
- 缺失战法配置：生成 fallback 事件，不阻塞战斗。
- 缺失装备配置：生成 fallback 事件，不阻塞战斗。
- 无合法目标：生成释放失败事件，进入普通攻击或结束行动。
- 配置字段无法解析：保留原始文本，生成 fallback 事件。

## 测试策略

- 配置测试：英雄成长、战法 detail、装备、装备特性、组合加成能加载。
- Builder 测试：英雄等级、装备、战法能构建到运行时单位。
- Modifier 测试：属性加成、增伤减伤、无视防御可叠加。
- SkillRuntime 测试：准备、冷却、发动率、目标选择、状态效果。
- Engine 测试：完整回合循环、状态跳过、战法优先、普通攻击 fallback。
- 集成测试：真实英雄 + 真实战法 + 真实装备组合完成一场 seeded battle 并输出压缩报告。

## 验收标准

- 所有英雄 ID 可通过 builder 接入战斗。
- 所有战法 ID 可进入战法运行时；已支持效果生效，未知效果有 fallback 事件。
- 所有装备 ID 可挂载到英雄；已支持属性/效果生效，未知效果有 fallback 事件。
- 完整测试套件 `./gradlew test` 通过。
- 战斗不会因为单个未知战法或装备效果崩溃。
