## 5. 尚未完成的 7 类效果

### 5.1 effect 111：引用效果额外参数

语义：为被引用 detail 注入额外参数，不是普通 buff。

正式配置示例：

```text
21096201 effect=111 effect_param=21096202 calc_pos=953 constant=50
21224401 effect=111 effect_param=21224403 calc_pos=953 constant=100
21224402 effect=111 effect_param=21224404 calc_pos=954 constant=100
29710701 effect=111 effect_param=29710702 calc_pos=991 calc_param=1 constant=2000000
```

建议设计：建立“引用 detail 执行覆盖”类型，不要继续返回通用 `MetaEffectChange`。覆盖至少需要保留：

```text
referencedDetailId
calcPosition
calcParameter
constant
configuredValue
生命周期/次数
```

执行 `TriggerReferencedEffectChange`、子技能或傀儡 detail 时，将有效覆盖合并进 `EffectInvocation`，而不是修改全局配置对象。

### 5.2 effect 112：引用效果数值变化

语义：修改被引用 detail 的效果数值。正式配置存在正数、负数、延迟、多回合和大整数编码：

20028332 -> 20028331, constant=6
20097935 -> 20097913, constant=40
21126205 -> 21126204, constant=10, delay_round=2, available_round=5
21196501 -> 21196502, constant=1000

不要统一当百分比。必须先查 `calc_pos`、引用 detail 的 `configuredValue` 和正式描述，再决定是加法、倍率、每回合增长还是替换。
